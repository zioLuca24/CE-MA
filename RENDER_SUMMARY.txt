## 🎯 COSA FARE ADESSO (30 minuti)

### STEP 1️⃣ Push su GitHub (1 min)
```bash
cd gestionale-edile
git add .
git commit -m "Render deployment: PostgreSQL + render.yaml + configs"
git push origin main
```

### STEP 2️⃣ Creare Database PostgreSQL (2 min)
1. Accedi: https://dashboard.render.com
2. Clicca: **"+ New"** → **"PostgreSQL"**
3. Compila:
   - Database Name: `gestionale_edile_prod`
   - User: `gestionale_user`
   - Region: `frankfurt` (o tua regione)
4. **SALVA** External Database URL + Password
5. Attendi: status = **"Available"**

### STEP 3️⃣ Creare Web Service (2 min)
1. Clicca: **"+ New"** → **"Web Service"**
2. Seleziona repo: `gestionale-edile`
3. Compila:
   - Name: `gestionale-edile`
   - Runtime: Java
   - Build Command: `mvn clean package -DskipTests -Prender`
   - Start Command: `java -jar target/gestionale-edile-1.0.0.jar`
   - Plan: Free

### STEP 4️⃣ Configurare Environment Variables (1 min)
Aggiungi nella sezione "Environment":
```
SPRING_PROFILES_ACTIVE = prod
DATABASE_URL = postgresql://gestionale_user:PASSWORD@dpg-xxxxxx.render.com:5432/gestionale_edile_prod
DB_USER = gestionale_user
DB_PASSWORD = (PASSWORD dal database)
PORT = 8080
JAVA_OPTS = -Xmx512m -Xms256m
```

### STEP 5️⃣ Deploy (10-15 min)
- Clicca: **"Create Web Service"**
- Render fa il build automaticamente
- Attendi il messaggio: "The application is running at https://gestionale-edile.onrender.com"

### STEP 6️⃣ Verifica (1 min)
1. Apri: https://gestionale-edile.onrender.com/api/
2. Login: admin / admin
3. Verifica: Cantieri, Personale, Materiali, Fornitori visibili

## 🚨 Se Qualcosa Va Male

### Build Failed?
→ Controlla log Render Dashboard  
→ Verifica: `mvn clean package -DskipTests` localmente

### Database Connection Error?
→ Verifica DATABASE_URL (copiato correttamente?)  
→ Verifica password  
→ Attendi 2-3 min dopo creazione database

### Applicazione Lenta?
→ Primo accesso è normale 30-60 sec  
→ Accessi successivi sono veloci
